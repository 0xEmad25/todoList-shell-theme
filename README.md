## This project is a todo list with a shell theme 

commands to use are: 

`add`: to add a new item to the list.

`done` [num]: to delete an item from the list with the index.

`ls`: to show all items in the list.

`exit`: to close the program

| commands | explanation |
| -----| ------|
| add | add a new item to the list |
| done [num]| delete an item from the list with the index |
| ls | show all items in the list |
| exit | close the program |
